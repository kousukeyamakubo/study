# 出力形式・受け渡し契約

ラベル生成・出力形式を扱うときに参照する。実装は
`../0817/lib/detections.py`。

## 検出結果CSV（`detect_yolo.py`の出力、統合前）

| カラム | 内容 |
|---|---|
| `frame` | フレーム番号 |
| `t_s` | 時刻 [s] |
| `track_id` | ByteTrackのトラックID（対応付け失敗時は`-1`。`docs/detection.md`参照） |
| `cls` | COCOクラスID |
| `conf` | 信頼度 |
| `x1, y1, x2, y2` | bbox |
| `foot_u, foot_v` | 接地点の画像座標（下辺中央） |

## 統合済み検出（`merge_cyclist()`の出力）

上記と同じカラム構成。`cls`が研究対象クラス文字列（`cyclist` / `vehicle` / `pedestrian`）に
置き換わり、cyclistの`foot_u, foot_v`は統合後の接地点（bicycleの下辺）になる。

## `run_pipeline.py` が出すファイル（`data/outputs/`）

| ファイル | 内容 |
|---|---|
| `<映像名>.ground.csv` | 地上座標ラベル（下記）＝**受け渡しの正本** |
| `<映像名>.ground.png` | 俯瞰図。既定で出る（`--no-plot`で抑止）。目視確認用で契約外 |
| `<映像名>_ground_frames/NNNNN.png` | フレーム毎の俯瞰図（`--plot-frames`時のみ）。連番＝フレーム番号。契約外 |
| `<映像名>.ground.mp4` | 上をつないだ動画（`--plot-frames`時のみ）。契約外 |
| `<映像名>_overlay.mp4` | bbox・接地点・track_idを重ねた動画（`--overlay`時のみ）。契約外 |

## 地上座標ラベル（`to_ground()`適用後）＝ ラベルの正本

統合済み検出に以下が追加される:

| カラム | 内容 |
|---|---|
| `X, Y` | 地上座標 [m]（マーカー基準の座標系。マーカー1を原点、1→2の向きをX軸とする等、現地で定義） |

**このCSVがラベルの正本。** h・俯角の推定値が変わっても、地上座標を作り直す必要はない
（h・俯角はホモグラフィの分解にのみ関わり、`to_ground`自体には不要）。

## 斜距離付き（`add_slant_range()`適用後、学習データ組み立て時のみ）

| カラム | 内容 |
|---|---|
| `R_slant` | レーダーから見た斜距離 [m]。`radar_xy`（レーダー位置）と`h`を渡して計算 |

この変換はレーダーの「位置」だけで決まり「向き」に依存しないため、カメラとレーダーの
ボアサイトを精密に合わせる必要はない。

## 受け渡し先

`../../400MHz変更用/0908/matching/`（S3: カメラ検出とレーダーピークの対応付け）が
地上座標ラベル（`X, Y` + クラス + `track_id`）を入力として受け取る。

- ゲート幅（レンジ・角度・SNR閾値）は現状は合成データでの仮値。実測の誤差統計が無いため
  実測同期データでの較正が必要（メイン側の未解決事項、`../../400MHz変更用/meeting/2026-09-08.md`参照）
- 角度はラベルとしては使わないが、対応付けのゲートには使える。ただし
  「一定dB以上のフレームのみ±20°の方位ゲートを掛ける」という条件付きの使い方に限定
  （低SNRでは角度推定の標準偏差が20.8°まで悪化し使い物にならなかったため）
