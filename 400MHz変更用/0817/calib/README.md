# カメラ内部パラメータ較正・h/俯角の試算（H3/S2）

**カメラ内部パラメータKを較正済み。既存マーカーデータと組み合わせて h=18.61m・俯角=40.10° を試算した。**
計算はできたが、この数値の信頼性は未検証（下記参照）。

| K（3840×2160較正、15/16枚検出） | fx=2872.1, fy=2883.4, cx=1928.9, cy=1038.8 |

| h（試算） | 18.61 m |
| 俯角（試算） | 40.10° |

h・俯角は`chessboard_calib.py`が出したKと、`0817/data/markers.csv`（8/16現地セッションのマーカー6点、
同じ3840×2160）を`pose_from_homography(H, K)`に渡して計算した。

### 信頼性が未検証な理由

1. **フォーカスの整合性が未確認**: チェスボードは机上・近距離（〜1m）で撮影、マーカー画像は
   現地の遠距離（20〜40m）シーン。オートフォーカスが働いていれば、近距離と遠距離で
   レンズの実効焦点距離がわずかに変わる可能性がある（`0817/README.md`が警告する
   「オートフォーカスが動くと較正が無効になる」点）
2. **独立な裏取りがまだ無い**: h・俯角の実測値（メジャー・下げ振り・傾斜計によるH4b、
   `meeting/2026-09-08.md`の持ち越し項目）はまだ取得されておらず、この試算値と突き合わせる手段が無い

「5階から見下ろす設置」という前提（1階3〜4m×5階分）とはオーダーとして矛盾しない値だが、
これは弱い整合性チェックに過ぎない。

## 較正手順の記録

`chessboard_images/`に3840×2160（本番と同一解像度）で撮影した15〜16枚を配置し、

```bash
python chessboard_calib.py "chessboard_images/*.jpg" --cols 9 --rows 6 --square-size 0.024 --out K.npz
```

内側コーナー数は9×6（縦7マス×横10マスのボード）、1マスの辺は定規実測で2.4cm。
