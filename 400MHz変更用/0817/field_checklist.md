# 現地チェックリスト（2026-08-16 日曜・カメラのみ）

レーダーは回さない。目的は **カメラ → 地上座標のパイプラインを実映像で通すこと**。

---

## 撮る前に必ず確認（ここを外すと映像が無駄になる）

- [ ] **マーカーに使う地物 4〜8 点と、自転車が走る範囲が、同じ画角に入っている**
      → 入っていない映像はホモグラフィが張れず、地上座標に変換できない
- [ ] **解像度・ズーム・フォーカス・露出を固定**した（オートフォーカスが動くと較正が無効になる）
- [ ] 本番と**同じ部屋・同じ窓**から撮っている（幾何を代表させるため）

## 地物の選び方

白線の交点・マンホールの縁・縁石の角・舗装の目地など。新たに物を置く必要はない。

- [ ] **点として一意に指せる**（「角」がよい。面や太い線は中心が曖昧）
- [ ] **自転車が走る地面と同じ平面上**（段差・縁石の上は不可）
- [ ] **4点が一直線に並んでいない**
- [ ] 走行範囲の**中心付近を覆っている**（遠方まで囲めなくても 1.2〜1.4 倍の悪化で済む）
- [ ] 6〜8 点あると、残差から測り間違いを検出できる（4 点だと検出不能）

横の広がりは不要（±2 m でも精度は変わらない）。道幅が取れなくてよい。

## 当日やること（優先順）

### 1. チェスボード較正の撮影（10 分）

- [ ] チェスボードを **15〜20 枚**、角度・位置・距離を変えて撮る
- [ ] **映像と全く同じカメラ設定**（解像度・ズーム・フォーカス）で撮る

用途: レンズ歪みの補正と、ホモグラフィ分解による h・俯角の算出。
同じ設定なら家で撮り直しても構わない。

### 2. 映像取得（30 分）★その日限り

- [ ] マーカー地物が写っている状態で **自転車の走行を 3 本以上**
- [ ] 走行前後に **静止した状態**を数秒ずつ入れる（検出の安定性確認用）
- [ ] 撮影中にカメラを動かさない（動かしたら別セッション扱いで撮り直し）

### 3. h・俯角の実測（10 分）★その日限り

- [ ] **h**: 窓から下げ振り／メジャーを垂らす（レーザーは反射しないことがある）
- [ ] **俯角**: 傾斜計（レーザー測定器の傾斜機能）

用途: カメラのホモグラフィ分解から出る値との突き合わせ。
**これ自体は必須ではない**（h はカメラから ±0.2 m で出る）が、独立な検証になるので安価に押さえる。

### 4. 接地点の系統誤差の測定（10 分）

- [ ] 協力者に **既知の地物の真上に立ってもらい**、静止した状態を撮る
- [ ] できれば **手前・中間・遠方の 3 箇所**で

用途: bbox 下辺と真の接地点の差を測る。合成データでは
「物体長による偏り cyclist −0.9 m」「高さの取り違えで 40 m で 2.25 m」と出ており、
**画素雑音（0.13 m）より遥かに大きい支配的な誤差**。実測で確認すべき最初の量。

### 5. 地物の相互距離（30 分・余裕があれば）

- [ ] マーカー地物の間をメジャーで測る（4 点なら 6 本。うち 1 本が検算になる）
- [ ] 巻尺で **cm オーダーで十分**（10 cm 誤差でも地上誤差は 0.15 m 程度）

**後日でもよい**。地物は動かないので、一度測れば以降のセッションで使い回せる。
当日測れなくても致命的ではない。
