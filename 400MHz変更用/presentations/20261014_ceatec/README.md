## 1. 同期動画

`video/<番号>_<シナリオ>_<app|dep>_<nomti|mti>_<ja|en>.mp4`（24 本、git 管理外）。
各動画の目標が最も強いフレームの静止画は `figures/still_<同じ名前>.png`。

- 1920 × 1080、H.264、5 fps（レーダー 1 フレーム = 0.2 s なので実時間で再生される）。20 s
- 上段の左がカメラ映像、右が Range-Angle マップ（扇形）、下段が Range Profile
- カメラ 1 枚 = レーダー 1 フレーム（`.cam` と `.dat` は 1:1 で対応する。weekly/0908 で確認済み）

| 量 | 中身 |
|---|---|
| Range Profile | 8 チャンネル × 全ドップラービンの電力和。灰色の線はその走行の時間中央値（背景） |
| Range-Angle | 全ドップラービンで素子方向 FFT（TDM 位相補正込み）した電力の和。扇形の x = R sin θ、y = R cos θ |
| MTI なし／あり | `atlas_export.py` の `--no-mti` ／既定（チャープ平均を引く） |

**見てほしいこと（観測）**
- MTI なしでは、Range Profile は現在のフレームと背景がほぼ重なり、目標は見分けにくい。Range-Angle は静止物（木・建物）の弧で埋まる
- MTI ありでは、静止物が消え、目標の山が距離と角度の上で動いていく（例: 番号 3 の t = 17.4 s で、R 約 26 m に背景より 20 dB 強い山）

**注意（スライドに書くかは任意）**
- 色の範囲（Range-Angle）と縦軸（Range Profile）は、MTI なし／あり・6 本すべてで共通にしている（−4〜41 dB、14〜57 dB）。どの動画どうしを並べても、色や高さの違いがそのまま dB の違いになる
- そのため MTI ありの目標は緑寄りに見える。目標（MTI ありで約 25 dB）は静止物（MTI なしで約 35〜40 dB）より弱く、MTI なしでは埋もれる、という関係がそのまま色に出ている
- R は斜距離。扇形は地面の上の位置そのものではない（レーダーは 5 階にある）
- 角度は「＋ を右」に描いた。接近する目標は角度が ＋ → − に動き、カメラ映像では右 → 左に動くので、この向きでカメラと左右がそろう（番号 3 で映像と照らし合わせて確認。番号 1 も角度は ＋ → − に動く）。角度の符号の定義そのものは未確認
- 角度の分解能は正面で 14.5° と粗いので、扇形の上の目標は横に広がって見える
- R < 8 m（窓枠などの直近の反射）は描いていない

## 2. 背景が変わった原因の材料

10/5 は、13:55 の 2 本（番号 1・2）と 14:22 以降の 4 本（番号 3〜6）で背景が違う。
原因の候補は **雨（風を含む）** と **14:00 ごろにレーダーに触って置き方が変わった** の 2 つ。
分析と数値の出どころは `weekly/1013/1005/README.md` §2・§3（`static_compare_1005.py`・`static_angle_1005.py`）。

| 素材 | 観測 |
|---|---|
| `figures/rain_static_fluct_*.png` 下段（フレームごとの揺れ） | 14:22 以降は R 16〜28 m（木の帯）だけ揺れが 15〜20 dB 大きい。R 40 m 以遠は 13:55 とほぼ同じ。14:22 以降の 4 本は、車が走った回も止まっていた回も同じ形 |
| 同 上段（静止物の強さ） | 多くの距離でよく重なる。違うのは一部の距離（R 13〜14 m で +4〜10 dB、R 18 m 付近で −2〜−6 dB、R 24 m 付近で −6〜−8 dB。`static_compare_log.txt`） |
| `figures/rain_shift_*.png` | 静止物の位置の角度のずれは、同じ回どうしで 0.28° 以内、回をまたぐと 0.7〜1.2°。10/1 → 10/5 の置き直し（5〜10°）より一桁小さい |
| `figures/rain_position_*.png` | 静止物の弧の位置（距離・角度）は 13:55 と 14:22 で同じで、強さが場所ごとに上下している |
| `figures/rain_camera_*.png`（参考） | 2 回の画角はほぼ同じ。映像から路面が濡れているかは判別できない |

**言えること（解釈。確からしさの順）**
1. 揺れの増加は、レーダーに触ったことでは説明できない。触ったのなら変化は一度きりで、20 s ずっと揺れが大きくはならない。木の帯にだけ出ているので、雨か風で木が揺れたと考えるのが合う（**確からしい**。ただし雨と風はデータでは区別できない）
2. 雨粒そのものや、レーダー自体の不安定さでもない。そうなら全距離で揺れるはずだが、R 40 m 以遠は変わっていない（**確からしい**）
3. 水平の向きは、触っていたとしても 1° 程度しか変わっていない。1° 回っただけでは静止物の弧が横に少しずれるだけで、強さが距離ごとに上下することは説明できない（**確からしい**）
4. 静止物の強さが一部の距離で上下したことは、雨（濡れ）でも、触って**俯角**が変わったのでも起こりうる。ATLAS のアンテナは横一列なので、上下の傾きはデータから測れない（**区別できない**）

`rain_position` の色（dB）は素子方向 FFT のあとの値で、`rain_static_fluct` の dB とは基準が違う。図どうしで dB の値は比べられない。

まとめると「揺れの増加は雨（風を含む）による。静止物の強さの一部の変化は、雨か、触って俯角が変わったかのどちらか」。
雨の降り始めの時刻と、13:56〜14:22 にレーダーに触ったかどうかは記録がない。
