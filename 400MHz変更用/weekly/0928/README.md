## 結論（エグゼクティブサマリー）

1. **真値（GT）はルート情報へ簡略化：** 走行ラインが既知であれば、横位置 $Y$ はライン番号として一意に確定できます。カメラ映像・YOLO・ホモグラフィ変換による追跡処理は一旦**凍結**します（検証および時刻同期用の映像記録のみ継続）。
2. **レーダー基準の座標系を採用：** カメラのホモグラフィ変換に依存せず、レーダーの設置位置・高さ $h$・アンテナ方向およびライン位置をレーザー測距計で実測し、幾何計算によって理論軌道 $R(t)$ および動径速度 $v_r(t)$ を算出します。
3. **ライン識別（$Y$ 方向）の高難度性を前提とした設計：** 5階からの見下ろし配置では、$\sqrt{Y^2+h^2}$ における $Y$ の感度が低く、ライン間の差は $R$ や $v_r$ の微小な変化としてしか現れません。本検証では単純な「識別の可否」ではなく、**「どの距離帯まで分離可能か」**を定量的に見極める課題として扱います。
4. **10/2 の報告はパイロット試行（24本）に特化：** 本番の大規模データ収録は 10/2 以降に実施します。今回の実験は単なる本番のリハーサルではなく、**「10/2 の報告で確実に言えること」から逆算したミニマム設計**とします。
5. **ニューラルネットワーク（NN）への入力は時系列（複数フレーム）を前提：** 単一フレームではライン間の差異が極めて小さく、$Y$ の識別に決定的な情報は「最接近付近における軌道の曲率変化」に集約されるためです。

## 幾何学的制約と課題の背景

### 1. なぜライン識別が難しいのか

レーダーから対象までの距離 $R$ は以下のように表されます：

$$R = \sqrt{X^2 + Y^2 + h^2}$$

アンテナ設置高 $h$（5階相当）が大きいため、横方向離隔 $\sqrt{Y^2+h^2}$ に対するライン位置 $Y$ の感度は低下します。さらに遠方（$X$ が大）になるほど距離 $R$ に対して $X$ が支配的となり、ライン間の幾何学的な距離差は急速に縮小します。  
したがって、**評価は全体の平均値ではなく、距離帯（ビン）ごとに分割して実施する**必要があります。全域平均のみで評価すると、遠方領域においてモデルが単に全体の平均値を出力するだけの「平均値退化」を起こしているケースを見落とす危険があります。

### 2. ドップラー情報が内包する角度成分

道路に沿って一定速度 $v$ で等速直線運動する場合、動径速度（視線方向速度） $v_r$ は次式で記述されます：

$$v_r = v\cos\theta = v\cdot\frac{X}{R}$$

進行方向が道路と平行（既知）であれば、観測値 $(R, v_r)$ および速度 $v$ から進行方向位置 $X = R\,v_r/v$ が求まり、横方向離隔 $d = \sqrt{Y^2+h^2} = \sqrt{R^2-X^2}$ が一意に定まります。すなわち、**Range-Doppler（RD）マップのドップラー成分には、本質的に視線角度の情報が含まれています。**

ただし、$v_r = dR/dt$ の関係から明らかなように、これは距離−時間軌道に含まれる情報と**幾何学的に等価**です。情報量が独立して増えるわけではなく、「単一フレームの瞬時値ではなく、時系列全体として現れる幾何特性である」という点に留意する必要があります。なお、$\cos\theta$ の左右対称性（方位の曖昧さ）については、レーダーを走路中心から片側にオフセット配置することで解消します。

### 3. NN（ニューラルネットワーク）設計への示唆

| 項目 | 方針と技術的意図 |
|---|---|
| **入力形式** | 最接近区間を含む時間窓の複数フレーム（時系列）。単一フレームではライン差が小さく判別が困難なため。 |
| **データセット** | ライン × 速度 × 方向 を**直交表形式で網羅**。条件に偏りがあると、モデルが速度とラインの擬似相関をショートカット学習してしまう危険があります（9/8 に確認された速度依存問題と同様）。 |
| **ベースライン** | 理論軌道モデル $R(t)^2 = (X_0+vt)^2 + d^2$ に対する幾何フィッティング。NN の性能がこの幾何フィッティングを上回って初めて、振幅情報やマイクロドップラー成分に有用な特徴量が含まれていることの証明となります。 |

## 実験設計

※ 記載の数値は下見（9/29）前の暫定値です。現地の道幅や実際の設置可能位置を踏まえて確定します。

### 1. 座標系および計測区間

原点は、レーダー設置位置を道路手前側の境界へ投影した点とします。$X$ 軸は道路延長方向（レーダーから遠ざかる向きを正）、$Y$ 軸は道路横断方向（奥に向かう向きを正）とし、レーダー座標を $(0, -y_r, h)$ と定義します。

| 項目 | 設定値 | 備考 |
|---|---|---|
| **評価区間** | $X = 3 \sim 23\text{ m}$ | 近距離端（3 m）は暫定値。5階からの見下ろし角により直下付近が垂直 FOV（視野角）外となる可能性があるため、9/29 の走路1往復で取得する反射強度プロファイルに基づき確定（強度が急落する境界点を FOV 端とみなす）。 |
| **道幅** | $Y = 0 \sim 4\text{ m}$ | 道路全体の有効幅。 |
| **総走行距離** | $26\text{ m}$ | 評価区間 20 m ＋ 前後の加減速区間各 3 m。 |
| **コーン配置** | $X = 3, 13, 23\text{ m}$ | 始点・中央・終点の計3本を設置。詳細は下記参照。 |

#### コーンの役割と時空間同期の仕組み
- **主目的（時刻と位置の対応づけ）：**  
  コーンの主たる目的は、**カメラ映像とレーダー観測の時空間同期**です。カメラ映像からコーンの通過フレームを特定することで、「その瞬間に被験者が既知の座標 $X$ に存在した」という事実が確定します。`.cam` の1画像フレームとレーダーの1データフレームは 1:1 で厳密に対応しているため、これがそのままレーダー側の確定時刻となります。この通過時刻こそが、幾何学的理論軌道 $R(t)$ を生成するための唯一の外部入力パラメータとなります。
- **中央コーン（$X=13\text{ m}$）の役割：**  
  20 m の評価区間を 10 m ずつに2分割することで、走行速度の等速性検証および真値の幾何計算精度を高めるために配置します。また、始点および終点のコーンは走者に対する走行範囲の視覚的なガイドを兼ねます。
- **座標系の基準と代替物：**  
  座標系自体はコーンではなく、レーダー設置位置およびレーザー実測による幾何パラメータ（$h, y_r$）によって定義されます。そのため、現地に映像上で一意に識別可能な地物（タイルの目地や街灯の基礎等）が存在する場合は、それらの相互離隔を実測した上でコーンの代替として利用可能です。

### 2. 実験条件

| 項目 | 設定内容 |
|---|---|
| **走行ライン** | **パイロット実験では最外側の2本（$Y=0.5, 3.5\text{ m}$）のみ**。本番実験にて4本（$Y=0.5, 1.5, 2.5, 3.5\text{ m}$）を実施。 |
| **走行速度** | 目標数値を強制せず、**ペダリングの感覚（漕ぎ方）で定義**（低速：歩行程度 / 中速：通常走行 / 高速：やや急ぎ足）。実速度は映像のコーン通過フレームから算出。 |
| **進行方向** | 「接近」および「離反」の2通り。往復走行を行うことで試行間の待機時間を短縮。 |
| **試行単位** | 1試行あたり1ファイル（30秒間収録）。ファイルと実験条件を 1:1 で厳密に対応づける。 |
| **背景データ** | クラッタ除去および参照用として、各測定セットで無人状態の背景を30秒間（1ファイル）収録。 |

- **低速域の設定意図：** 自転車と歩行者の速度域をオーバーラップさせ、速度情報以外の運動学的特徴（マイクロドップラー等）で識別可能かを検証するため（9/8 検討項目 C の検証）。
- **速度上限の管理：** ドップラーの折り返し限界（$\pm4.80\text{ m/s}$）に対し、視線方向の動径速度は実走行速度以下となるため、走行速度を $4.0\text{ m/s}$ 未満に抑えることで安全に折り返しを回避可能。
- **バイアス対策：** 被験者の疲労、日照変化、機器の熱ドリフトなどの外的要因との交絡を防ぐため、**反復試行ごとにブロック化を行い、ブロック内での実施順をランダムにシャッフル**する。

#### 9/29 実施分における割り切りの内容と根拠

9/30 に別件の予定が入ったため、下見とパイロット収録を 9/29 に同日実施します。時間的制約から、本来の設計から**速度水準の多重化（低速条件）を落とし**、中速1水準に固定します。

**落とせる理由**：速度水準を振る目的は、自転車と歩行者の速度域を重ね合わせ、速度以外の運動学的特徴で識別可能かを検証すること（9/8 検討項目 C）にあります。これは**クラス識別に関する検証**であり、10/2 で報告する主張 (1)(2)（ライン識別の幾何的分離性）には寄与しません。したがって、今回の報告内容を毀損することなく削減できます。

**削減により失うもの**：速度とクラスの交絡を切る検証は 10/2 では扱えません。これは**本番収録（10/2 以降）で実施**します。

**削減しない次元**：
- **方向（2通り）**：往復走行のため、離反を収録すれば復路で接近も収録できます。追加コストがほぼゼロであり、片道のみにすると復路が完全な移動ロスになるため、削減対象としません。
- **反復（3回）**：「条件間の差が同一条件内のばらつきを超えるか」が主張 (2) そのものであるため、削減すると報告が成立しません。

**段階的実施**：まず上記12本を確実に収録します。時間および被験者の体力に余裕がある場合に限り、低速水準12本を追加します。

> [!NOTE]
> **反復回数3回に関する統計的留意点：**  
> サンプルサイズ $n=3$ では信頼性のある分散推定は困難です。したがって、パイロット段階での目的は統計的な分散評価ではなく、「同一条件の軌跡が目視レベルで整合して重なるか」の確認に留めます。本番実験で必要な反復回数は、この確認結果を踏まえて決定します。

## 想定されるリスクと対策（コンティンジェンシープラン）

| 潜在的リスク | 発生時の対応方針 |
|---|---|
| **直下付近が垂直 FOV 外となり、近距離端（3 m）が欠損する** | 評価区間全体を遠方側へシフトさせ、有効区間長（20 m）を確保する。 |
| **セットバック $y_r$ が十分に確保できない**（夜間実測の結果次第） | 横離隔が狭まることでライン識別（$Y$ 方向）の分離難度は高まりますが、進行方向位置 $X$ の推定精度や検知性能そのものは影響を受けません。主張 (2) を「幾何情報のみでは分離困難（No）」として整理し、次フェーズの最優先タスクとして複数アンテナによる角度推定（未決事項1）の導入検討へ移行します。 |
| **樹木の葉による電波減衰が無視できない** | 単なる実験の失敗要因としてではなく、実環境の外乱特性として評価します。信号減衰が生じた区間を特定・除外した上で主張 (2) のライン間比較を行い、減衰区間のデータ自体は「樹木・植栽がレーダー反射に与える実測影響」として報告に含めます（9/24 の指摘に対する直接の回答）。 |
| **最外側2ラインの距離差が同一条件内のばらつきに埋もれる** | 主張 (2) に対する「No（分離不可）」の検証結果として報告します（用意したプロット図をそのまま工学的考察として活用可能）。 |
| **走行速度のばらつきが大きく、条件間の分離が曖昧になる** | 算出された実速度に基づいて事後的に層別解析（ビン分割）を行います。本番実験に向けてペダリングの統一基準を再調整します。 |

## 未決事項・検討課題

1. **複数アンテナによる角度推定（アレイ信号処理）の適用可否：**  
   角度推定が実用可能であれば、ライン識別のアプローチは角度推定を主軸とし、ドップラー情報は補助的な位置づけへと移行します。システム全体の設計方針に直結するため、早期の実現性確認が望まれます。
2. **信号処理パイプラインの入力形式：**  
   デジタルビームフォーミング（DBF）によって角度情報へ統合した上でモデルへ渡すか、生（Raw）の位相情報をそのまま保持して渡すか（9/8 からの継続課題）。データ保存方針として複素生データを保持する方針は確定しているため、アルゴリズム側の判断は先送り可能です。
3. **「1 m 間隔ライン識別」に対する要求水準のすり合わせ：**  
   教員側が期待している主眼が「距離情報」「角度情報」「ドップラー（マイクロドップラー）情報」のどこに置かれているかについて、10/2 のミーティングを通じて意識合わせを行います。
