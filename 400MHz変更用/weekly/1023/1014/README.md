# 縦の線：壁に向けた収録を、発表と同じ Range Profile で見直す（10/14）

10/13 の発表では、縦の線について次のように言った（`meeting/2026-10-13.md`「3. 縦の線は扱える」）。

1. 壁に密着させても線が出る → 外の物の反射ではない
2. 正体は少なくとも 2 種類（IF に入った妨害と、約 78 kHz おきの並び）
3. 1 回の収録の中では安定しているので、無人背景で距離ごとの床を測り、しきい値を上げれば扱える

1 の根拠（`../../1013/1011/wall_check.py`）はドップラー最大の量しか見ておらず、発表で見せた電力和の Range Profile では確かめていなかった。
ここでは、壁の収録（10/11 の 2 本、各 10 s）を発表と同じ量で作り直し、10/12 の無人背景・10/1 夜と並べる。

- スクリプト `wall_range_profile.py`、ログ `wall_range_profile_log.txt`
- 図 `figures/wall_rt.png`（壁の距離−時間図。色の範囲は発表の図と同じ）、`figures/wall_profile.png`（線の高さを収録ごとに並べたもの）
- 線の高さ ＝ 電力和・MTI ありの時間中央値 − 距離方向の床（±5 m の中央値）

## 観測

**MTI で減るか**（線の距離での「MTI なし − MTI あり」、電力和の時間中央値）
- 壁の 34 m：+0.3〜0.4 dB（床と同じ。MTI ではまったく減らない）
- 壁の 17 m：+4.2〜7.9 dB（一部は減る）
- 10/12 の 39.8 m は +2.0〜7.0 dB で、その収録の床（+5.1〜8.3 dB）と同じかそれ以下。28.8 m は +22.5〜29.8 dB（最も強い静止物の距離）

**時間的に安定か**（線の距離での、フレームごとの標準偏差）
- 壁・10/12 では、線の距離でも 0.4〜0.6 dB で、線のない距離（0.4〜0.5 dB）と同じ

## 解釈（未検証）

**発表で言ったことのうち、言い切れるもの**
- 「外の物の反射ではない線がある」：言える。壁の 17・34 m は、外が見えない状態で、発表と同じ量でも 10 s ずっと出る
- 「線は 1 回の収録の中では安定している」：言える。だから、無人背景で距離ごとの床を測ってしきい値を上げる、という扱いは、線の正体が分からなくても成り立つ

**言い過ぎだったもの**
- 「10/1 夜の線は、壁と同じもの（約 78 kHz おきの並び）」：言えない。
  位置が 2 ビンずれ、高さも半分以下で、同じくらいの山がほかにもある。34 m は、強い静止物の MTI の引き残しと区別できない
- 「線の正体は少なくとも 2 種類」：根拠が弱い。壁で確かめられたのは 17・34 m の 1 組だけ。
  10/12 の 3 本（22.9・28.8・39.8 m）は、窓で変わらないこと（`../../1013/1012/README.md` L）と、39.8 m に静止物の山がないことまでしか分かっていない。
  反射か妨害かは、この 3 本についてはまだ決められない

**発表でどう言い直すか（案）**
- 「縦の線の一部は、レーダー側から来る妨害（壁でも出る）。ほかの線の正体は分かっていない。
  ただ、どの線も 1 回の収録の中では安定しているので、収録ごとの無人背景で距離ごとの床を測って扱う」
- 原因の特定は、扱いが成り立つ限り急がない、という位置づけは変えない。ただし、扱いの前提（収録の中で安定）は、毎回の無人背景で確かめる

**言い切るために足りないもの**
- 野外の収録と同じ日に、同じ PC・USB ポートで壁の収録を撮る（今は壁と野外が別の日で、構成の記録もない）
- 壁の収録で、USB ポート・外部電源つきハブ・別の PC を変えて、17・34 m が消えるかを見る（`../../1013/1011/README.md`「この先」にある切り分け）
