## 3. 解釈（未検証）

- **見える距離の帯は置き方で変わる**：自転車も車も同じ R 約 37 m で切れ、10/1 とは帯がずれている。
  帯を決めているのは目標の強さより置き方（ビームの向き）と考えられる。ただし傾きと走路の R の記録がないので、確かめられない
- **角度は収録ごとに基準が要る**：残差が全走行で同じ向きに −5〜−10° 出ているのは、置き直しで yaw が変わったためと考えられる。
  レーンの記録がないので、レーンの違いと区別できない
- **背景の違いは雨による**：濡れで静止物の強さが変わり、木の帯（R 21〜30 m）が遅く揺れる形と合う。
  雨粒そのものなら全距離・広いドップラーに出るはずで、レーダー側の揺れなら全距離で同じ割合になるはずで、どちらとも合わない。
  13:55 に降っていなかったかは確かめていない
- 上の解釈が正しければ、車と自転車の比較、止めた車の有無の比較は、どちらも雨の有無と混ざっている
