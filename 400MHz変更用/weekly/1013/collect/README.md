# 週末の研究室収録の準備（実行役 2、10/5）

手元のデータの見直し（9/28 の窓 → `../0928/README.md`、10/1 夜の背景 → `../1001/README.md` B）をもとに、
週末に 1 回だけ撮る収録の計画を固めた。撮った後の分析は別途。

## 1. 窓：週末に見ること

H2（置き方 a、同じレーン1の離反を開→閉→閉→開）で、`check_run_1013.py` の遠い帯（R 40〜49 m）のスコアを比べる。

- 窓を閉めてよい: 閉で遠い帯が 3 dB 以上出て、かつ前後の開との差が 3 dB 以内
- 閉めない: 開との差が静止物で測った値（約 8 dB）に近い。この場合は「窓は開ける」で確定する

## 2. 背景を引くために収録で守ること

1. 録画を始めたら、操作者は終わりまで動かない。目標は録画開始から 5 s 待ってから出す（最初の 5 s は捨てる前提）
2. 置き方・窓を変えるたびに、変える前と後で無人背景 30 s を撮る。背景と走行の間で三脚・レーダーに触らない（触ったら背景を撮り直す）
3. 三脚の近く（R < 5 m）に人や物を置かない。操作者は三脚から離れて、PC だけを触る
4. 段差は避けられないので、解析ではフレームごとの共通位相を戻してから背景を引く（`../1001/background_recheck.py` の `common_phase`）
5. 風の強さを備考に書く（R 21〜30 m の木の揺れが、背景の引き残しの最大の要因）

## 3. 収録計画

記録表: `run_sheet.csv`（`make_run_sheet.py`、seed 1013）。全 24 ファイル、約 80 分（このほかに設置・コーン測量 30 分）。

| 優先 | 内容 | 本数 |
|---|---|---|
| A | H2 窓（置き方 a、開→閉→開、レーン1の離反）＋ H1 置き方 b（レーン1 ×2）＋ 前後の背景 | 走行 4・背景 7 |
| A' | H1 置き方 c（レーン1 ×2）＋ 前後の背景。**b で近い端が見えたら撮らない** | 走行 2・背景 2 |
| B | H2 の 2 本目（閉の 2 本目、開に戻した後の 1 本）、各置き方のレーン3 | 走行 5 |
| C | H4 車の徐行 1 往復（最も見えた置き方で） | 2 |
| D | a に戻して 1 本（時間による変化の確認）＋ 最後の背景 | 走行 1・背景 1 |

- 置き方 a のレーン1 は、H2 の「開」の 2 本で兼ねる
- 自転車は C1 の手前から助走し、C1 を巡航速度で通過する（離反の出だしで v_r ≈ 0 にならないように）
- 時間が足りないときは D → C → B → A' の順に削る（約 66 → 56 → 50 → 30 分）。A は削らない

## 4. 現地での確認

```
python check_run_1013.py <file>.dat --lane 1 --dir dep     # 走行
python check_run_1013.py <file>.dat --bg                   # 無人背景
```

- 1 本 約 10 s。出力は次の 3 行と、図 `data/check/<file>_check.png`
  1. 近い端 R 22〜28 m のスコア → 【見えた】（3 dB 以上）/【弱い】（1.5〜3 dB）/【見えない】。中・遠の帯も併記
  2. 床（R 13〜20 / 20〜28 / 40〜60 m）と、9/28 の開・閉の値
  3. 共通位相の段差（5 s 以降、前後 1 s の中央値の差 > 20 mrad）→ 【安定】/【段差あり】。段差ごとに室内の動きも出す
- d（最接近距離）は 10/1 の幾何から出し、±1.5 m で総当たりする。置き方 c で大きく変わったら `--d` で与える
- 10/1 夜のデータで試した結果: No.20（レーン1の離反）は近 −0.4 / 中 +2.6 / 遠 +4.1 dB。10/2 報告の値と同程度に出る
