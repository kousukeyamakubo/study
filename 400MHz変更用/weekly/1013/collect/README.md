# 週末の研究室収録の準備（10/5 作成、10/9 にゴールに合わせて組み直し）

10/8 にゴールを「N=16 で TS 22.137 カテゴリ 2 の見逃し・誤警報 5% に届かせる」に決めた（`../README.md`「今週の目的」）。
この収録の一番の役目は、10/1 夜のデータで決めた処理が**別のデータでも 5% に届くかを確かめる**ための走行を撮ること（`../1008/README.md` T3）。
10/5 版の計画（置き方 a/b/c と窓の比較が中心）は、この役目に合わせて優先度を入れ替えた。撮った後の分析は別途。

## 0. この収録で撮るもの

| 優先 | 何のため | 内容 |
|---|---|---|
| A | 5% に届くかを確かめる（`../1008/` T3） | 置き方 a・窓 開（10/1 夜と同じ条件）に固定して、徒歩・自転車 × レーン 1・2 × 接近・離反を各 2 本。無人背景を最初・途中・最後に |
| B | 窓を閉めてよいか | 窓を閉めて自転車レーン1の離反 ×2、開け直して ×1 |
| D | 仰角方向のパターンの材料（任意） | 反射板つきコーンの差分測定 |
| C | 近い帯が見えるようになるか | 置き方 b（下へ 15〜20°）で自転車レーン1の離反 ×2 |

- **撮らないもの**：車（カテゴリ 2 の対象は人。近い帯が見えないのはビームのせいだと 10/5 で分かった）、レーン 3（10/1 夜で直接波がほぼ見えず、真値の軌跡が作れない）、置き方 c
- **A の本数の根拠**：見逃しが 5% 以下だと言うには、見逃し 0 件なら約 60 事象が目安（3/n ≤ 0.05）。
  10/1 夜は中・遠の帯で 1 本あたり約 40 フレーム（12 本で 482）なので、16 本で約 640 フレーム。同じ走行のフレームは独立ではないので、本数の側でも 16 本を確保する
- **目標がいないときの誤警報（Type 1）**：背景 30 s のうち最初の 5 s を捨てて約 125 フレーム。A の 3 本で約 375 フレーム
- A の中では、レーダー・三脚・窓に触らない。触ったら傾きを測り直して備考に書く

## 1. 設置で記録すること

真値（既知のレーンを等速で走る軌跡）を BEV に写すのに、高さ h と道路からの引き y_r が要る（`../1008/README.md`）。

| 項目 | 測り方 | いつ |
|---|---|---|
| 高さ h | 窓からレーザー距離計で真下の地面まで。1 m の誤差で R=30 m の俯角が約 2° ずれる程度なので、だいたいでよい | 設置時 |
| 傾き | スマホの画面をレーダーの板の面に当て、水準器アプリで読む。水平の向き（yaw）はスマホでは測れないので、今までどおり既知のレーンに当てはめて求める | 設置時・置き方を変えた後・終わり |
| コーンの斜距離 | 今までどおりレーザーで直接測る。レーンの R の真値は h から逆算せず、これを使う | 設置時 |
| 天気・風 | 備考に書く。10/5 は雨で比べられなかった | 設置時・変わったとき |

## 2. 窓：見ること（優先 B）

窓を閉めた 2 本と、A の同じ条件（自転車レーン1の離反、窓 開）の走行を、`check_run_1013.py` の遠い帯（R 40〜49 m）のスコアで比べる。
閉めた後に開け直した 1 本で、時間による変化を確かめる。

- 窓を閉めてよい: 閉で遠い帯が 3 dB 以上出て、かつ開との差が 3 dB 以内
- 閉めない: 開との差が静止物で測った値（約 8 dB）に近い。この場合は「窓は開ける」で確定する

## 3. 背景を引くために収録で守ること

1. 録画を始めたら、操作者は終わりまで動かない。目標は録画開始から 5 s 待ってから出す（最初の 5 s は捨てる前提）
2. 置き方・窓を変えるたびに、変える前と後で無人背景 30 s を撮る。背景と走行の間で三脚・レーダーに触らない（触ったら背景を撮り直す）
3. 三脚の近く（R < 5 m）に人や物を置かない。操作者は三脚から離れて、PC だけを触る
4. 段差は避けられないので、解析ではフレームごとの共通位相を戻してから背景を引く（`../1001/background_recheck.py` の `common_phase`）
5. 風の強さを備考に書く（R 21〜30 m の木の揺れが、背景の引き残しの最大の要因）

## 4. 収録計画

記録表: `run_sheet.csv`（`make_run_sheet.py`、seed 1013）。全 30 ファイル、約 66 分（このほかに設置・コーン測量 30 分）。

| 優先 | 内容 | ファイル数 | 所要 |
|---|---|---|---|
| A | 設置の記録 ＋ 確かめる用の走行 16 本（順はシャッフル）＋ 背景 3 本 | 19 | 約 28 分 |
| B | 窓を閉める → 背景 → 自転車 ×2 → 背景 → 窓を開ける → 自転車 ×1 | 5 | 約 12 分 |
| D | 背景 → 反射板つきコーンを置く → 30 s（任意） | 2 | 約 8 分 |
| C | 置き方 b に傾ける → 背景 → 自転車 ×2 → 背景 → 終わりの傾き | 4 | 約 18 分 |

- 実施順は A → B → D → C。置き方を変える C は最後にして、a には戻さない
- 時間が足りないときは C → D → B の順に削る（約 66 → 48 → 40 → 28 分）。A は削らない
- 自転車は C1 の手前から助走し、C1 を巡航速度で通過する（離反の出だしで v_r ≈ 0 にならないように）。徒歩はふだんの速さで一定に歩く

## 5. 現地での確認

```
python check_run_1013.py <file>.dat --lane 1 --dir dep     # 走行（--lane 1/2、--dir app/dep）
python check_run_1013.py <file>.dat --bg                   # 無人背景
```

- 1 本 約 10 s。出力は次の 3 行と、図 `data/check/<file>_check.png`
  1. 近い端 R 22〜28 m のスコア → 【見えた】（3 dB 以上）/【弱い】（1.5〜3 dB）/【見えない】。中・遠の帯も併記
  2. 床（R 13〜20 / 20〜28 / 40〜60 m）と、9/28 の開・閉の値
  3. 共通位相の段差（5 s 以降、前後 1 s の中央値の差 > 20 mrad）→ 【安定】/【段差あり】。段差ごとに室内の動きも出す
- d（最接近距離）は 10/1 の幾何から出し、±1.5 m で総当たりする。置き方 b で大きく変わったら `--d` で与える
- 10/1 夜のデータで試した結果: No.20（レーン1の離反）は近 −0.4 / 中 +2.6 / 遠 +4.1 dB。10/2 報告の値と同程度に出る
- 優先 A の走行は、遠い帯が 3 dB 以上なら次へ進む。届かないときは、ふらつき・通行人などを備考に書いて同じ条件をもう 1 本撮る
