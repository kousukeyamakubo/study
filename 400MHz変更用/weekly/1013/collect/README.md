# 週末の研究室収録の準備（実行役 2、10/5）

手元のデータ（9/28 の窓、10/1 夜）を見直して、週末に 1 回だけ撮る収録の計画を固めた。
撮った後の分析は別途。dB はすべて相対値で、速度ビンはビン番号で切っている。

## 1. 窓

**結論**: 距離ごとの床で正規化すれば、窓を閉めても誤警報は増えない。
ただし屋外の静止物はガラスで約 8 dB（往復）落ち、R 20〜40 m では床も 2〜3 dB 上がる。
目標が同じだけ落ちるなら、窓を閉めると目標の見え方は約 10 dB 悪くなり、10/1 夜の遠い帯（レーン1で 4.2 dB）は消える。

図: `figures/window_recheck.png`（`window_recheck.py`）

- 誤警報率 1e-3 に要る床超過（R 13〜60 m、MTI あり）: 閉 7.8 dB、開 13.0 dB。
  開の方が悪いのは、R 20〜27 m の ±1 ビンにある遅い動き（植生と見られる）による。窓を閉めるとこの動きも落ちる
- 床の上昇（閉 − 開）: R 13〜20 m で +5.9、20〜28 m で +2.2、28〜40 m で +3.1、40〜60 m で +0.3 dB。
  閉めたときの代表フレームでは、R ≈ 5 m と 33〜36 m に、ドップラー方向に平らな縞が出る
- 屋外の静止物（MTI なしの DC ビン）の落ち込み: R 20〜55 m の 37 ビンの中央値で 8.1 dB（四分位 7.1〜10.1）。
  10/5 の予備分析の「約 4 dB」は帯の取り方が違う（手前のガラス自体の反射が混ざっている）
- 9/28 の「窓を閉めると計測できない」の根拠（誤警報）は誤り。ただし目標側の損失で、結論は変わらない可能性がある

**週末に見ること**: H2（置き方 a、同じレーン1の離反を開→閉→閉→開）で、`check_run_1013.py` の遠い帯（R 40〜49 m）のスコアを比べる。

- 窓を閉めてよい: 閉で遠い帯が 3 dB 以上出て、かつ前後の開との差が 3 dB 以内
- 閉めない: 開との差が静止物で測った値（約 8 dB）に近い。この場合は「窓は開ける」で確定する

## 2. 背景

**結論**: 静止物の反射の変化は、全距離・全チャンネルで共通の位相の段差（30〜90 mrad）で、振幅はほぼ変わらない（揺れは 0.03 dB）。
録画開始から約 5 s は操作者の動きで、さらに大きく揺れる（100〜250 mrad）。
共通位相を戻せば No.19 の段差は消える。ただし複素の背景差分でも電力領域の正規化でも、MTI より良くはならない。どの方式でも近い端は見えない。

図: `figures/background_recheck.png`（`background_recheck.py`）

- No.19 の t ≈ 22 s の段差: 全距離・全 8 チャンネルで同じ位相の跳び（約 −90 mrad）。室内の動きは +2.5 dB で静か
- 段差は、レーダー内部の位相の跳びか、三脚の視線方向の微小な動き（0.03 rad ≈ 30 µm）のどちらか。この 2 つはデータでは区別できない。
  10/1 夜の 5 本中 4 本で、5 s 以降に段差があった（うち No.1 の 5.4 s は操作者の動きと同時）。No.20 の段差（20.2 s）は室内 R ≈ 2 m の小さな動き（+5.6 dB）と同時。
  段差が 20〜24 s に集中している（No.19, 20, 32）
- No.1, 31 の冒頭の揺れは、室内（R 0.5〜5 m）の動体電力の跳ね（+13〜24 dB）と同時に起きている → 操作者
- 軌跡上の目標強度（4 走行の中央値、時刻反転の対照からの上乗せ、近 21〜30 / 中 30〜40 / 遠 40〜49 m）:
  MTI 0.1 / 2.0 / 2.3 dB、位相補正つき複素差分 −2.0 / 1.9 / 2.3 dB、電力領域の正規化 −0.2 / 1.1 / 2.2 dB
- 位相を補正しても、DC ビンの残差は静止物から 15〜30 dB しか下がらない。最も悪いのは R 21〜30 m（木の帯）。
  別のファイルの背景を引くと、残差はさらに 2〜6 dB 増える
- MTI なしでは、強い静止物の窓関数の裾が動体ビンに漏れる。電力領域で正規化しても、静止物の強い距離（R 30〜36 m）では目標が MTI より薄い

**背景を引くために収録で守ること**

1. 録画を始めたら、操作者は終わりまで動かない。目標は録画開始から 5 s 待ってから出す（最初の 5 s は捨てる前提）
2. 置き方・窓を変えるたびに、変える前と後で無人背景 30 s を撮る。背景と走行の間で三脚・レーダーに触らない（触ったら背景を撮り直す）
3. 三脚の近く（R < 5 m）に人や物を置かない。操作者は三脚から離れて、PC だけを触る
4. 段差は避けられないので、解析ではフレームごとの共通位相を戻してから背景を引く（`background_recheck.py` の `common_phase`）
5. 風の強さを備考に書く（R 21〜30 m の木の揺れが、背景の引き残しの最大の要因）

## 3. 収録計画

記録表: `run_sheet.csv`（`make_run_sheet.py`、seed 1013）。全 24 ファイル、約 80 分（このほかに設置・コーン測量 30 分）。

| 優先 | 内容 | 本数 |
|---|---|---|
| A | H2 窓（置き方 a、開→閉→開、レーン1の離反）＋ H1 置き方 b（レーン1 ×2）＋ 前後の背景 | 走行 4・背景 7 |
| A' | H1 置き方 c（レーン1 ×2）＋ 前後の背景。**b で近い端が見えたら撮らない** | 走行 2・背景 2 |
| B | H2 の 2 本目（閉の 2 本目、開に戻した後の 1 本）、各置き方のレーン3 | 走行 5 |
| C | H4 車の徐行 1 往復（最も見えた置き方で） | 2 |
| D | a に戻して 1 本（時間による変化の確認）＋ 最後の背景 | 走行 1・背景 1 |

- 置き方 a のレーン1 は、H2 の「開」の 2 本で兼ねる
- 自転車は C1 の手前から助走し、C1 を巡航速度で通過する（離反の出だしで v_r ≈ 0 にならないように）
- 時間が足りないときは D → C → B → A' の順に削る（約 66 → 56 → 50 → 30 分）。A は削らない

## 4. 現地での確認

```
python check_run_1013.py <file>.dat --lane 1 --dir dep     # 走行
python check_run_1013.py <file>.dat --bg                   # 無人背景
```

- 1 本 約 10 s。出力は次の 3 行と、図 `data/check/<file>_check.png`
  1. 近い端 R 22〜28 m のスコア → 【見えた】（3 dB 以上）/【弱い】（1.5〜3 dB）/【見えない】。中・遠の帯も併記
  2. 床（R 13〜20 / 20〜28 / 40〜60 m）と、9/28 の開・閉の値
  3. 共通位相の段差（5 s 以降、前後 1 s の中央値の差 > 20 mrad）→ 【安定】/【段差あり】。段差ごとに室内の動きも出す
- d（最接近距離）は 10/1 の幾何から出し、±1.5 m で総当たりする。置き方 c で大きく変わったら `--d` で与える
- 10/1 夜のデータで試した結果: No.20（レーン1の離反）は近 −0.4 / 中 +2.6 / 遠 +4.1 dB。10/2 報告の値と同程度に出る
