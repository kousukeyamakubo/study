# A. 36 走行のドップラー−時間・角度−時間（実行役 1）

10/2 の指摘「ドップラー−時間、角度−時間のマップも作る」への対応。`python axes_maps.py`（出力ログは `run_log.txt`）。
データは `weekly/1001/data/export`（MTI あり）と `export_nomti`（MTI なし → フレーム間差分）。

## 図

| 図 | 内容 |
|---|---|
| `figures/doppler_time_{walk,bike}.png` | ドップラー−時間（R 15〜55 m で距離方向の最大）。3 行（繰り返し）× 6 列（レーン・向き）|
| `figures/angle_time_{walk,bike}.png` | 角度−時間（各フレームの最強動体セルの角度スペクトル、`to_ra` で TDM 位相補正込み）。赤点は期待角度 |
| `figures/*_fd.png` | 上の 2 つの MTI なし＋フレーム間差分版（DC ビン込み）|
| `figures/angle_vs_range.png` | 時刻を使わず、(最強セルの R, 角度) をレーン別に散布し、3 レーンの期待角度と重ねる |
| `figures/angle_residual_by_run.png` | 走行ごとの「レーン1 の期待角度からの残差」（R 30〜45 m の中央値）を収録順に |
| `figures/runs/NoXX_*.png` | 1 走行ずつ、MTI / 差分 × 距離・ドップラー・角度。近い端 R 22〜28 m を網掛け |

色のスケールは MTI あり / 差分で共通（距離・ドップラー 15〜45 dB、角度スペクトル 0〜30 dB）。
差分は独立な雑音 2 フレームの差なので、雑音床はそれだけで約 +3 dB 高く出る。
各パネル上端の白いバーが横軸の分解能 1 個ぶん（距離 0.846 m、速度 0.60 m/s、角度は正面 14.5° と 30° で 16.7°。角度は正面から離れると約 1/cos θ 倍に広がる）。

角度の符号の向きは未検証。期待角度は、アレイ軸が水平で走路方向から yaw だけ回っているとして
u = (X cos yaw + x sin yaw)/R とし、yaw と符号を自転車レーン1 に当てはめた（yaw −35.5°、誤差の中央値 0.6°）。

## 結果

- **a. 近い端の時間帯の痕跡**: ある。ただし R 22〜28 m ではなく **R 33〜37 m** に出る。
  離反では本体の筋（R 28〜32 m から）より数秒先に、接近では本体が消えた後に、
  遅いドップラー（±0.6 m/s = 1 ビン）で角度が −20°→0°（離反）/ 0°→−20°（接近）と連続的に動く成分がある。
  角度は近い端の期待角度（レーン1 で R 22 m → −21°、R 25 m → 約 0°）と合うが、距離は真値より約 10 m 長い。
  自転車の全レーンで見え、徒歩では見えない（遅いので MTI で消える可能性）。
  多重反射（往きか帰りの一方が何かで反射した経路）の候補だが未検証。根拠: `figures/runs/No22_bike_lane1_dep.png`
- **b. レーンごとの角度**: 違う。R 30〜45 m で、レーン2 はレーン1 より +1.3〜2.4°（11 本すべて）、レーン1 は −0.6〜+0.6°（12 本すべて）。
  期待は +1.6°。収録順で徒歩レーン2 の後に自転車レーン1 が 0 に戻るので、時間的なずれでは説明できない。
  yaw をレーン1 自転車で決めているので、独立な確認は徒歩レーン1 とレーン2。根拠: `figures/angle_residual_by_run.png`
- **c. レーン 3**: 直接波は角度でも見えない（R 30〜45 m で目標ありのフレームが 1 本につき 0〜1）。
  a の R 33〜37 m の成分だけは、自転車レーン3 でも他のレーンと同程度に出る。根拠: `figures/angle_vs_range.png`

## 判断に迷ったこと・未検証のこと

| 項目 | どう決めたか | 結論への影響 |
|---|---|---|
| a の R 33〜37 m の成分の正体 | 多重反射（往きか帰りの一方が何かで反射した経路）を候補として挙げただけで、確かめていない | a の「目標が弱いだけではない」は言えるが、近い端が見えない原因そのものは未特定 |
| 期待角度の yaw | 設置の向きの記録がないので、自転車レーン1 に当てはめて決めた（−35.5°） | b のレーン1 自転車 ≈ 0 は自明。独立な確認は徒歩レーン1 とレーン2 だけ |
| 期待角度のモデル | アレイ軸が水平（ロールなし）、素子間隔 λ/2 と仮定。どちらも未検証 | b の期待差 +1.6° の値に効く。観測したレーン1/2 の分かれ方そのものには効かない |
| 角度の符号の向き | 未検証のまま。図にも明記 | yaw の当てはめで吸収されるので、b・c の結論には効かない |
| 「目標あり」の判定 | 最強セルは雑音だけでも必ず選ばれるので、走行内の中央値から +6 dB 以上とした（しきい値は目で決めた値） | 下げるとレーン3 の点は増えるが、雑音や静止物の残差が混ざる |
| b の外れ値の除外 | レーン1 の期待角度から 8° 以上外れた点は a の成分などとみなして除外 | a の成分（負の角度）は R 33〜37 m で b の帯に重なるので、除外しないと混ざる |
| MTI なしの図 | 生の RD は静止物で埋まるので、フレーム間差分にして描いた | 近距離の静止物のゆらぎ（+20° 付近の帯）が最強セルを占め、最接近点付近の判断にはほぼ使えなかった。徒歩の近い端は MTI ありでもなしでも判断できていない |

# B. 背景の時間変化と背景の引き方（実行役 2）

10/2 の指摘「背景データを引いた方がいい」への対応。データは `weekly/1001/data/export_nomti`（夜 No.1, 19, 20, 31）。
夜は無人背景を撮り忘れたので、背景はファイル自身の時間中央値で代用している。

**結論**: 静止物の反射の変化は、全距離・全チャンネルで共通の位相の段差（30〜90 mrad）で、振幅はほぼ変わらない（揺れは 0.03 dB）。
録画開始から約 5 s は操作者の動きで、さらに大きく揺れる（100〜250 mrad）。
共通位相を戻せば No.19 の段差は消える。ただし複素の背景差分でも電力領域の正規化でも、MTI より良くはならない。どの方式でも近い端は見えない。

図: `figures/background_recheck.png`（`background_recheck.py`）

- No.19 の t ≈ 22 s の段差: 全距離・全 8 チャンネルで同じ位相の跳び（約 −90 mrad）。室内の動きは +2.5 dB で静か
- 段差は、レーダー内部の位相の跳びか、三脚の視線方向の微小な動き（0.03 rad ≈ 30 µm）のどちらか。この 2 つはデータでは区別できない。
  10/1 夜の 5 本中 4 本で、5 s 以降に段差があった（うち No.1 の 5.4 s は操作者の動きと同時）。No.20 の段差（20.2 s）は室内 R ≈ 2 m の小さな動き（+5.6 dB）と同時。
  段差が 20〜24 s に集中している（No.19, 20, 32）
- No.1, 31 の冒頭の揺れは、室内（R 0.5〜5 m）の動体電力の跳ね（+13〜24 dB）と同時に起きている → 操作者
- 軌跡上の目標強度（4 走行の中央値、時刻反転の対照からの上乗せ、近 21〜30 / 中 30〜40 / 遠 40〜49 m）:
  MTI 0.1 / 2.0 / 2.3 dB、位相補正つき複素差分 −2.0 / 1.9 / 2.3 dB、電力領域の正規化 −0.2 / 1.1 / 2.2 dB
- 位相を補正しても、DC ビンの残差は静止物から 15〜30 dB しか下がらない。最も悪いのは R 21〜30 m（木の帯）。
  別のファイルの背景を引くと、残差はさらに 2〜6 dB 増える
- MTI なしでは、強い静止物の窓関数の裾が動体ビンに漏れる。電力領域で正規化しても、静止物の強い距離（R 30〜36 m）では目標が MTI より薄い

ここから導いた収録のときの守りごとは `../collect/README.md` §2。
