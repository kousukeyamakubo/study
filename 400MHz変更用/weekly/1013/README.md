### 解釈（未検証）

- 角度は、軌跡としてならレーンを分けうる。置き直すと yaw が変わるので、使うなら収録ごとに既知のレーンで基準を取る必要がある
- R 33〜37 m の成分は多重反射の候補
- 見える距離の帯は、目標の強さより置き方（ビームの向き）で決まっている
- 窓を閉めると、目標もガラスで落ちるなら見え方は悪くなる
- 背景を引く方式は、10/1 夜のデータ（無人背景なし）では MTI に勝たない
- CFAR の前段としても MTI が最も良い。MTI なしは静止物が CA-CFAR の訓練セルに入ってしきい値を押し上げる（マスキング）とみられる
- 10/5 の揺れの増加は雨（風を含む）による。静止物の強さの変化は、雨と、レーダーに触って俯角が変わったことの区別がつかない（水平の向きは 1° 程度しか変わっておらず、強さの変化は説明できない）。
  どちらにしても、10/5 の車と自転車の比較は、雨か置き方の変化と混ざっている
- カテゴリ 2 は、系の性能（更新周期・距離分解能・速度分解能）と対象（屋外の人）が ATLAS とほぼ同じなので、N=16 の合格ラインに使える
- 今の中・遠の帯の検出率 0.51 / 0.65 は、フレーム単位の見逃しに読み替えると 49 / 35% で、5% から遠い。ただし 3GPP の数え方に直す前の値

## 判断

- 次の収録では、自転車・徒歩を 1 本ずつ、前後に無人背景つきで撮る。背景を引く方式が MTI より良いかを見て、車の回にも背景を撮るかを決める（10/6）
- （案）記録表に傾き・レーン・コーンの斜距離・天気を書く。比べる条件は同じ天気のうちに続けて撮る
- 合格ラインは TS 22.137 カテゴリ 2 の見逃し・誤警報 5% とする。位置精度（2 m）の評価は、独立な真値が要るので後回し（10/8、ミーティングで確認）
- 真値は「既知のレーンを等速で走る」軌跡。v と t0 は N=16 で決めて固定し、N を減らした評価にも同じものを使う（10/8）
- 検出と真値の対応づけは BEV の位置だけで決め、ドップラーは使わない。ドップラーのビン幅は N で変わるため（10/8）
- 10/13 ミーティングの指摘を受けて（詳細は `meeting/2026-10-13.md`「10/13 で言われたこと」）：
  - 全 N 共通・ドップラーなしの処理の流れは、ISAC の文脈ならよい。ただし先に、ミリ波レーダーをインフラ側に置いて検出・識別する研究がどこまでできているかをサーベイする
  - クラッタ除去（MTI・背景差分・フレーム差など）は、論文をもとに候補を挙げ、選ぶ理由（例：環境の変化に強いか）をつける
  - 研究の売り方を決める：ミリ波の交通センシングとして売るか、ISAC につなげるか。どちらでも「なぜ時分割 ISAC か」（通信とセンシングの相互作用を考えなくてよい）と、自分たちの ISAC の系の定義が要る
  - 真値は LiDAR で自転車の動きを記録する案を検討する（コーン＋カメラの代わり）
  - ほかに調べること：チャープの諸元（16 チャープの中身）、天気の影響
