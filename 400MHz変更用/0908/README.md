# 実測パイプライン 全体像（0908フェーズ）

経緯・議論の記録は `meeting/2026-09-08.md`、モデル全体の背景は `docs/` を参照。
本ファイルは**このフェーズが何を目指し、各部品がどう繋がるか**をトップダウンで
まとめたもの（各フォルダのREADMEは手順・結果、ここは全体の位置づけ）。

## 1. このフェーズの目的

8/17までの検討で、モデルの入力設計に関する論点が1つ残った。

> **角度情報を DBF で潰してから渡すか、生の位相のまま渡すか**
> （DBFは14.5°量子化＝40mで±10m相当、ラベル精度0.13mと2桁差。生位相なら分解能限界に
> 縛られないが実測データ量が性能の天井になる）

この判断に必要な材料（実測SNR・素子間位相の安定性）を得ることと、どちらに転んでも
使える**実測の学習データを集めること**が0908フェーズの主軸。付随して、8/17で指導教官から
出た指摘6点（窓開閉比較・ターゲット無し比較・後処理・カメラマッチング等）にも答える。

## 6. 進んでいない核心：H1（本番撮影）

上記の表からわかる通り、**机上でできる部品（S1・S3骨格・S5・H3/S2・H8）はすべて完了しているが、
これらはどれもH1（実測データ）が無いと先に進めない**。具体的には:

- S3の実測較正・3体以上の対応付け検証 → 実測同期データが必要
- S4（教師テンソル組み立て） → S1〜S3の実測適用が前提
- DBF vs 生位相の判断 → 本題そのものが実測待ち
- H4・H5・H6・H7・H9（現地でのハード検証全般） → 撮影セッションと不可分

つまりこのフェーズのボトルネックはコード側ではなく**撮影の実施**にある。
