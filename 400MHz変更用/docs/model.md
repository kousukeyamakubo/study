# モデル構造（検討中）

## モデル: RadarLightUNet

`check.ipynb` に実装。

### 入出力形状

- **入力**: (B, N_FIXED=10, H, W) — 各角度の RD マップ
- **出力**: (B, 3, N_FIXED=10, H, W) — 各角度チャネルの3クラスlogits（背景/サイクリスト/車両）

### 角度ヘッドの独立性

各角度チャネルに対して独立したヘッドを持つ設計。
共有 UNet 特徴量に各角度の入力 RD マップ(1ch)を連結してから Conv で出力することで、
各角度チャネルを同一モデルで処理しつつ角度ごとの差異を吸収する。
