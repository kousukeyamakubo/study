# 研究概要

## 研究背景・位置づけ

ミリ波帯（28GHz）における ISAC（Integrated Sensing and Communication）システムの開発を行っている。
ここでは**時分割型 ISAC** を想定しており、センシングと通信を時間で切り替える構成をとる。

通信品質を確保するため、連続センシング時間は非常に短く設定されている。
現状は動作実績のあるチャープ数で固定しているが、将来的にはさらに短縮することを目指している（センシング時間はチャープ数で決まる）。

## センシング方式

- センシングにはチャープ信号（FMCW ライク）を使用
- DFT/FFT によってレンジ・ドップラー（RD）マップを生成
- 16 素子アンテナアレイを用いて角度方向の情報を取得

## 研究の流れ

| フェーズ | 内容 |
|---|---|
| 卒論 | MUSIC 法による角度推定 → DFT/FFT で RD マップ作成 → CFAR 検出 |
| DICOMO 提出 | 固定角度グリッドの RD マップスタックを入力とする UNet 検出器を構築。WaveFarer（建物なし・見通しあり）の CSV で検証 |
| 8/17 まで | WaveFarer のシナリオを建物あり NLOS 交差点に更新し、同モデルで再検証 |
| 実測フェーズ（0908〜） | **sim は一旦保留**。主軸は実測データ収集と後処理の整備に移行。詳細は `meeting/2026-09-08.md`・`0908/README.md` を参照 |

実測フェーズでの主な変更点:

- **検出対象を車両からペデストリアンに変更**（サイクリスト vs pedestrian の識別）。速度エイリアシングの問題を避けるため
- **角度情報の渡し方（DBF で潰す／生の位相のまま渡す）が未決定**。実測での SNR・素子間位相の安定性データが揃うまで判断を保留し、複素 `.npz` のまま両対応できる形でデータを収集している
- 下記の「問題設定」（N_FIXED=10 角度グリッド・3 クラス logits）は **sim ベースの旧モデル** の仕様。実測モデルの入出力設計は上記の判断待ちで未確定

## 問題設定（sim ベース・旧モデル）

- **入力**: N_FIXED=10 個の固定角度グリッドから得た RD マップスタック (B, 1, N_FIXED, H, W)
- **出力**: 各ボクセルの 3 クラス logits (B, 3, N_FIXED, H, W)（背景=0 / cyclist=1 / vehicle=2）
- **検出対象**: サイクリスト・車両（同一 RD ビン上に重なる場合も含む）

角度グリッドの種類（wide / narrow）は `docs/dataset.md` を参照。  
レーダー仕様・シナリオ詳細・物理的な注意事項は `docs/simulation.md` を参照。

## 評価指標

- **Hit rate**: 予測ピークが真値から (d_tol=2, r_tol=3) ビン以内に入った割合
- シナリオテスト: r_diff（レンジビン差）を変化させて近距離分離性能を評価
