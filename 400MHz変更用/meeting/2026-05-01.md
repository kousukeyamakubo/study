# 議論メモ 2026-05-01

## 前回（4/30）の結論を受けた方針転換

4/30 の実験で `Conv3d (3,3,3)` は角度軸をまたぐ特徴抽出により隣接チャネルに高確信度 FP を生む構造的な問題があり、ラベル・損失・学習率を変えても解消できないことが確認された。

一方、CFAR との比較設計を議論する中で「NN の本来の動機はサイドローブ起因の FP を後処理なしに解決すること」という原点に立ち返り、検出段まで含めた end-to-end 設計に方針を変更した。

---

## 設計方針：クラス別分離ヒートマップ + end-to-end 検出

### なぜ2つのラベルに分けたか

従来の設計では cy と ve のヒートマップを**1枚の配列に合成**していた：

```
y = zeros(N_FIXED, H, W)
y[cy_ch] += cy_heatmap   # cy を書き込む
y[ve_ch] += ve_heatmap   # ve も同じ配列に書き込む
```

この設計では「ピークが cy なのか ve なのか」の情報が失われるため、後処理の `match_peaks_to_targets`（真値との距離で cy/ve を割り当て）が必須だった。

**分離した理由：**
- マッチングを不要にする（クラスが最初から分かれている）
- モデルが「cy はどこ」「ve はどこ」を独立して学習できる
- cy ヒートマップは cy だけ、ve ヒートマップは ve だけを表現するため、クラス間の混乱が起きない

### アーキテクチャ変更

`RadarUNet3DIntensity` の head を2つに分割：

```python
# 変更前：1つの head
self.head = nn.Conv3d(fixed_channels, 1, kernel_size=1)
return out.squeeze(1)  # (B, N_FIXED, H, W)

# 変更後：cy/ve 独立した head
self.cy_head = nn.Conv3d(fixed_channels, 1, kernel_size=1)
self.ve_head = nn.Conv3d(fixed_channels, 1, kernel_size=1)
return cy_logits, ve_logits  # (B, N_FIXED, H, W) each
```

backbone（encoder・decoder）は共有したまま、最終層だけクラス別に分岐する。

### 検出方法の変更

**変更前：** 閾値 + 3D NMS でピークリストを作成 → `match_peaks_to_targets` で cy/ve に割り当て

**変更後：** クラス別ヒートマップそれぞれから argmax で1点取り出すだけ

```python
def decode_class_detections(cy_logits, ve_logits, exist_threshold=0.5):
    def _detect(logits):
        prob = torch.sigmoid(logits[0])
        if prob.max().item() < exist_threshold:
            return (-1, -1, -1)   # 物体なし
        # argmax で位置を決定
        return (ch, d, r)
    return _detect(cy_logits), _detect(ve_logits)
```

- `max > 0.5` が「物体が存在するか」の判断（学習で max が 0 か 1 に近づくため、0.5 固定で十分）
- `argmax` が位置の決定
- マッチング不要・NMS 不要

### この設計が成立する前提

データセットの各クラスが最大1物体（valid_cy ∈ {0,1}、valid_ve ∈ {0,1}）であるため、argmax で1点取れば十分。同クラスに2物体以上が登場するシナリオが追加された場合は設計の見直しが必要。

### 閾値の恣意性について

従来の閾値（0.7〜0.9 のチューニング）と異なり、exist_threshold=0.5 は「0 に近い値か 1 に近い値かを二値判断するだけ」なので感度が低く、実質的に恣意的な調整が不要。

## 実装変更まとめ

| 変更箇所 | 変更内容 |
|---|---|
| `RadarUNet3DIntensity` | head を cy_head / ve_head に分割、forward が (cy_logits, ve_logits) を返す |
| `MultiTargetDataset` | ラベルを y_cy / y_ve に分離（合成なし） |
| `decode_peaks_from_logits` | `decode_class_detections` に置き換え（argmax + exist判定） |
| `compute_loss` | cy/ve それぞれに focal loss を計算して合算 |
| `run_epoch` | 新出力形式に対応、match_peaks_to_targets を削除 |
| `MODEL_PATH` | `best_detector_3d_class_separate.pt` |
